# Number Guesser Game Project

## Description
This Project is a simple number guessing game where the player has to guess a randomly generated number within a certain range. The game provides feedback on whether the guessed number is too high, too low, or correct.

## How to Play
1. The game will generate a random number within a specified range (e.g., 1 to 100).
2. The player will be prompted to enter their guess.    
3. The game will provide feedback on the guess:
   - If the guess is too high, it will inform the player to guess lower.
   - If the guess is too low, it will inform the player to guess higher.
   - If the guess is correct, it will congratulate the player and display the number of attempts taken.
4. The player can choose to play again or exit the game after guessing the correct number.

## Features
- Random number generation within a specified range.
- Feedback on guess accuracy.
- Attempt tracking.
- Option to play again or exit.


## Installation
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Run the game using a Python interpreter.
